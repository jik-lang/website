Jik v0.1.0-beta.1 is out

Jik v0.1.0-beta.1 is out! This update adds a few handy CLI commands and fixes some memory issues.

  • jik new my-project creates a small project template to get you started.
  • jik test finds and runs tests in your project.
  • jik run now passes arguments after -- to your program.

There are also fixes for allocation-size overflow, temporary string buffers, and unnecessary copies of dictionary keys in the support library.

Get the new version from the installation page. See the CLI docs for the new commands, or check the release notes for the full list of changes.
