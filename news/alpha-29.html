Binary file I/O and new standard library helpers in Jik v0.1.0-alpha.29

Jik v0.1.0-alpha.29 is available. This release adds binary file operations, a string search helper, and a math function for two-dimensional distances. It also expands how throwing functions can report errors.

Read and write binary files

The jik/io module now supports rb, wb, and ab file modes. Use read_bytes or read_file_bytes to read data that may contain NUL bytes, and write_bytes to write it. The existing text operations remain available for strings.

Search strings and calculate distances

jik/string adds contains(s, needle) for substring checks. jik/math adds hypot(x, y), which computes the distance from (0, 0) to (x, y).

Report errors with a code

Throwing functions can now call fail(message), fail(code), or fail(message, code). This lets an application attach an error code, a message, or both to a recoverable failure.

The release also includes a fix for region allocation in safe calls and updates the region examples.
