Download the latest release archive for your platform, extract it, and add Jik to your PATH. To run or build programs, you also need a C compiler: GCC or Clang.

1. Set up Jik and a C compiler

Windows

  1. Download the Windows x64 ZIP from the latest release.
  2. Extract the whole archive to a stable location, for example C:\tools\jik. Keep its files and folders together.
  3. Add the directory containing jik.exe to your user PATH. Search the Start menu for "Edit environment variables for your account", edit Path, and add the directory as a new entry.
  4. Open a new terminal and check that Jik is available:
jik help

If you do not already have GCC or Clang installed, choose one of these portable GCC toolchains:

  • WinLibs: Download a Win64 / x86_64 GCC build, extract it, and add its mingw64\bin directory to your user PATH.
  • w64devkit: Download the x64 kit, extract it, and add its bin directory to your user PATH.

Open a new terminal after changing PATH, then check the C compiler:

gcc --version

If you use Clang instead, check clang --version.

Linux

The Linux download is for x64 systems with glibc 2.34 or newer. On older systems, use a newer distribution or build Jik from source.

On Ubuntu or Debian, install GCC and the tools used below:

sudo apt update
sudo apt install build-essential curl ca-certificates
gcc --version

On other distributions, use your package manager to install GCC or Clang, the C development headers, and curl. If a C compiler is already set up, you can keep using it.

  1. Download and extract Jik into your home directory with the commands below.
  2. The export command makes Jik available in the current terminal.
  3. Run jik help to check the installation.
mkdir -p "$HOME/.local/share/jik"
curl --fail -L -o /tmp/jik-linux-x64.tar.gz \
  https://github.com/jik-lang/jik/releases/download/v0.1.0-beta.1/jik-v0.1.0-beta.1-linux-x64.tar.gz
tar -xzf /tmp/jik-linux-x64.tar.gz -C "$HOME/.local/share/jik" --strip-components=1
export PATH="$HOME/.local/share/jik:$PATH"
jik help

To keep Jik available in new terminals, add this line to your shell's startup file (for Bash, ~/.bashrc; for Zsh, ~/.zshrc), then open a new terminal: 

export PATH="$HOME/.local/share/jik:$PATH"

2. Create and run a project

In a directory where you keep your projects, run the following commands. Choose a location where a directory named hello does not already exist. 

jik new hello
cd hello
jik run src/hello.jik

The first command creates the source file and a README. The last command runs the program. You should see Hello, world! in the terminal.

Jik looks for Clang, GCC, then cc automatically. To choose a compiler for this run, use: 

jik run src/hello.jik --cc gcc

Use --cc clang for Clang. You can also set the JIK_CC environment variable to choose a default compiler. See the CLI reference for more commands.

Use Packages

After the compiler is installed, see the Packages page for official package setup, JIK_PKG_PATH configuration, and import examples.

VS Code Extension

Download the .vsix file from the latest release above. In VS Code's Extensions view, open the ... menu, choose Install from VSIX..., and select the downloaded file.

Or, if the code command is available, open a terminal in the folder containing the downloaded file and run: 

code --install-extension "./jik-language-tools-v0.1.0-beta.1.vsix"
